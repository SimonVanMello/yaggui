Each repository you open gets a tab in the title bar. This page covers opening, closing, reopening, switching, reordering, pinning and renaming tabs, what their indicators mean, and what yaggui remembers between launches.

## Open and close tabs

- **New tab**: click **+** at the end of the tab strip, or press <kbd>⌘T</kbd> (<kbd>Ctrl+T</kbd> on Windows and Linux). A new tab shows the welcome screen, where you pick a repository (see [Open a repository](../../start-here/open-a-repository/)). Pressing it on a welcome tab focuses its search field instead of adding another empty tab.
- **Close a tab**: click its **×**, middle-click it, press <kbd>⌘W</kbd> (<kbd>Ctrl+W</kbd> on Windows and Linux), or press <kbd>Delete</kbd> while the tab has focus. <kbd>⌘W</kbd> closes the tab, never the window. Closing the last tab leaves a new welcome tab.
- **Reopen a closed tab**: press <kbd>⌘⇧T</kbd> (<kbd>Ctrl+Shift+T</kbd> on Windows and Linux), or choose **Reopen closed tab** in a tab's context menu, in the palette, or (macOS) **File › Reopen Closed Tab**.

After a tab closes, the tab to its right becomes active (or the one to its left).

Closing a tab never asks for confirmation. It cancels any yaggui command still running or waiting for that repository (a fetch, a push…) and closes its integrated terminals. Your files, changes and stashes, and a merge or rebase stopped on conflicts, stay as they are. To get the tab back, reopen it or open the repository again from the welcome screen.

### Reopen closed tab

yaggui remembers the last 10 repository tabs you closed since it started (welcome tabs are not remembered, and the list is not kept after you quit). Each <kbd>⌘⇧T</kbd> brings back the most recently closed one:

- it comes back at the place it had in the strip, or at the end when that place no longer exists, and becomes the active tab;
- a pinned tab comes back pinned;
- its layout (panels, left panel sections, graph columns) comes back with the repository, as described in [Layout remembered per repository](#layout-remembered-per-repository);
- if the active tab is a welcome tab, as after closing the last tab, the repository opens in it.

Tabs closed together with **Close other tabs** or **Close tabs to the right** come back one per press, from left to right, each at its former place. A repository you opened again in the meantime, or removed from the recents, is skipped. When the repository's folder has moved or been deleted, yaggui offers to locate it or remove it instead (see [Moved or deleted repositories](../../workspaces/workspaces/#moved-or-deleted-repositories)). **Reopen closed tab** is greyed out when there is nothing to reopen.

## One tab per repository

A repository opens in a single tab. Opening a repository that already has a tab switches to that tab instead of creating a second one. To work on two branches side by side, use a [worktree](../../repository/worktrees/): each worktree is a separate repository with its own tab.

## Switch between tabs

| Shortcut                                                                                   | Effect                                                       |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| <kbd>Ctrl+Tab</kbd> / <kbd>Ctrl+Shift+Tab</kbd>                                            | Next / previous tab. This uses the Control key on macOS too. |
| <kbd>⌘1</kbd> … <kbd>⌘8</kbd> (<kbd>Ctrl+1</kbd> … <kbd>Ctrl+8</kbd> on Windows and Linux) | Go to the tab at that position, pinned tabs included.        |
| <kbd>⌘9</kbd> (<kbd>Ctrl+9</kbd> on Windows and Linux)                                     | Go to the last tab, however many there are.                  |

When a tab has keyboard focus, <kbd>←</kbd> / <kbd>→</kbd> move to the previous or next tab (wrapping around), and <kbd>Home</kbd> / <kbd>End</kbd> to the first or last one.

The palette also offers **New tab**, **Close tab**, **Reopen closed tab**, **Next tab** and **Previous tab**. All these shortcuts are defaults that you can change: see [Palette and shortcuts](../../customize/palette-and-shortcuts/).

Switching between recently shown tabs is instant: yaggui keeps the last three repository views ready, and catches up on changes that happened while a tab was hidden.

## Reorder tabs

- **Drag** a tab along the strip.
- With a tab focused, press <kbd>⌘⇧←</kbd> / <kbd>⌘⇧→</kbd> (<kbd>Ctrl+Shift+←</kbd> / <kbd>Ctrl+Shift+→</kbd> on Windows and Linux).
- Use **Move left** / **Move right** in the tab's context menu.

When tabs no longer fit, they shrink evenly, then the strip scrolls: use the mouse wheel over it.

Pinned tabs and the other tabs each keep to their side: a pinned tab moves only among the pinned tabs, and another tab cannot go before them.

## Pin tabs

Choose **Pin tab** in a tab's context menu to keep a repository at hand:

- pinned tabs always sit at the left of the strip, in the order you give them (drag them, or use **Move left** / **Move right**, within the pinned tabs);
- a pinned tab is compact: the colored dot and a short name, without the **×**; its indicators (spinner, warning icon, change count) stay, and its tooltip says **Pinned**;
- **Close other tabs** and **Close tabs to the right** leave pinned tabs open;
- you can still close a pinned tab on purpose: <kbd>⌘W</kbd>, middle click, <kbd>Delete</kbd> on the focused tab, or **Close tab** in its context menu.

**Unpin tab** puts it back as the first tab after the pinned ones. Pinned tabs are restored pinned on the next launch. Welcome tabs cannot be pinned.

## Rename a tab

Choose **Rename…** in a repository tab's context menu. The **Rename repository** dialog changes the display name of the repository, not its folder: the new name shows in its tab, on the welcome screen, in the workspaces and in the palette. Leave the **Name** field empty to go back to the folder name. A name has at most 60 characters; spaces around it are ignored. The colored dot is computed from the name, so it can change color with it.

## Tab context menu

Right-click a tab:

| Item                           | Available when                                          | Effect                                                |
| ------------------------------ | ------------------------------------------------------- | ----------------------------------------------------- |
| **Close tab**                  | Always                                                  | Closes this tab.                                      |
| **Close other tabs**           | Another tab is not pinned                               | Closes every other tab, except pinned tabs.           |
| **Close tabs to the right**    | A tab to its right is not pinned                        | Closes the tabs to its right, except pinned tabs.     |
| **Reopen closed tab**          | A tab was closed                                        | Reopens the last closed tab (see above).              |
| **Pin tab** / **Unpin tab**    | Repository tabs                                         | Pins or unpins the tab.                               |
| **Rename…**                    | Repository tabs                                         | Opens the **Rename repository** dialog.               |
| **Move right** / **Move left** | The tab is not at that end of its group (pinned or not) | Moves the tab one place.                              |
| **Copy path**                  | Repository tabs                                         | Copies the repository path and shows **Path copied**. |

A repository tab shows a colored dot (computed from the repository name, so it stays the same unless you rename it), the repository name, and:

| Indicator          | Meaning                                                                                                                                              |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spinner            | The repository is opening, or an operation (fetch, rebase, push…) is running.                                                                        |
| Amber warning icon | A merge, rebase, cherry-pick, revert, bisect or patch application is in progress, or there are conflicts. See [Conflicts](../../history/conflicts/). |
| Red error icon     | The repository could not be opened.                                                                                                                  |
| Number badge       | Number of changed files: staged, modified, untracked and conflicted.                                                                                 |

Hover a tab to see a tooltip with the name, the full path and a status line, for example "Rebase in progress · 1 conflict · 6 changes", or **Could not be opened**. Screen readers get the same text.

## Restore tabs on restart

yaggui saves your tabs shortly after every change: their order, which ones are pinned, the active tab, and the layout of each. On the next launch, each repository tab reopens.

If a repository cannot be opened again, its tab shows the error with **Retry** and **Close tab**. When its folder no longer exists, the tab also offers **Locate…** (pick the new folder, see [Moved or deleted repositories](../../workspaces/workspaces/#moved-or-deleted-repositories)) and **Remove from recents**. See [Open a repository](../../start-here/open-a-repository/). A tab whose repository you removed from yaggui reopens as a welcome tab.

## Layout remembered per repository

The size and collapsed state of the panels, the sections of the left panel and the graph columns are saved per repository. When you open a repository again, in any tab, it comes back with the layout you left it with.
