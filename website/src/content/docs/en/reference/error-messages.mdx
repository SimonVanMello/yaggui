When something fails, yaggui shows a message written for people, not the raw Git output, and offers the next step as a button when there is one. This page explains where errors appear, then lists every message by area so you can search for the text you see.

## How errors are shown

<Screenshot
  dark={errorToastRetryDark}
  light={errorToastRetryLight}
  alt="Error toast titled Fetch failed, with the message, a collapsed Details section and a Retry button"
/>

- **Toast**: most errors appear as a toast in the bottom-right corner. Error toasts stay until you close them (the **×** button, or swipe right). Warnings, such as a merge stopped on conflicts, close on their own after a few seconds. A failed operation's toast is titled after it, for example "Fetch failed" or "Push failed", with the message below.
- **Inline panel**: when the error belongs to a dialog or a panel, it appears inside it, and the dialog stays open so you can fix the input. Examples: the **Open a repository** dialog, a repository tab that could not open ("Could not open the repository", "Could not open \{name\}"), the commit box.
- **Banner**: some states are shown as a banner above the graph instead: a Git lock file, automatic refresh unavailable, an operation in progress (see [Conflicts](../../history/conflicts/)).
- **Dialog**: a few errors open a dedicated dialog, for example local changes in the way of a checkout, or an undo that would overwrite local changes.

Each error can have:

- **Details**: a collapsed section with the raw technical text, usually what Git printed on stderr. Expand it to see Git's exact words; select the text to copy it.
- **An action button**: the fix yaggui can run for you. The labels are listed below.

An error that is not one of yaggui's typed errors (a bug in the interface) shows a toast titled "Something went wrong", with the technical text under **Details**. Please [report it](../../help/troubleshooting/#report-a-bug).

### Action buttons

| Button                    | What it does                                                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Retry**                 | Runs the failed action again.                                                                                                                                                                                       |
| **Refresh**               | Reloads the data (file list, diff, branches) and runs the action again.                                                                                                                                             |
| **Open command log**      | Opens the [command log](../../reference/command-log/), switches its filter to **All** if needed, and expands and highlights the last failed command with its full output.                                           |
| **Trust this folder…**    | Asks for confirmation, then runs `git config --global --add safe.directory <path>` and opens the repository again. See [Repository won't open](../../help/troubleshooting/#the-repository-belongs-to-another-user). |
| **Remove the lock…**      | Asks for confirmation, then deletes the stale `index.lock`. See [Another Git process is using this repository](../../help/troubleshooting/#another-git-process-is-using-this-repository).                           |
| **How to install Git**    | Explains how to install Git 2.30 or later.                                                                                                                                                                          |
| **Set your identity**     | Opens the identity form in the commit box.                                                                                                                                                                          |
| **Choose a terminal…**    | Opens the terminal setting.                                                                                                                                                                                         |
| **Pull then push**        | Pulls with your default strategy, then pushes again.                                                                                                                                                                |
| **Set upstream and push** | Pushes again and sets the upstream, after confirmation.                                                                                                                                                             |

A button only appears when it makes sense where the error happened: for example **Retry** needs an action to repeat.

## Reading the catalog

The tables below list each message as yaggui shows it in English. Parts in braces are filled in: `{path}` is a folder or file path, `{name}` a branch, tag or remote name, `{short}` a 7-character commit hash. The French interface shows the same messages in French. The last column gives the internal error code, which you can quote in a bug report.

yaggui recognizes Git's own errors by their English text (it runs Git with `LC_ALL=C`), so the matching works whatever your system language. A Git failure that matches nothing in the catalog shows "The Git command failed." with Git's output under **Details**.

## yaggui internals

These messages point to a bug or a broken local setup rather than a Git problem. If one appears, [report it](../../help/troubleshooting/#report-a-bug) with the content of **Details**.

| Message                                        | When it happens                                                                   | What to do                                                                                                          | Code                          |
| ---------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| The Git command failed.                        | Git failed with an error yaggui does not recognize. **Details** has Git's output. | Read the output. Button: **Open command log**.                                                                      | <small>gitFailed</small>      |
| Unexpected error.                              | An internal failure (file system, repository read). **Details** has the cause.    | Retry; report it if it persists.                                                                                    | <small>internal</small>       |
| yaggui could not read or write its local data. | The settings database or `keybindings.json` could not be read or written.         | Check the [data folder](../../reference/data-and-privacy/#where-yaggui-stores-its-data) permissions and free space. | <small>storage</small>        |
| Operation cancelled.                           | You cancelled an operation. Usually shown as "\{op\} cancelled".                  | Nothing to do.                                                                                                      | <small>cancelled</small>      |
| Repository #\{id\} is not open.                | The repository tab was closed while an action was running.                        | Open the repository again.                                                                                          | <small>repoNotOpen</small>    |
| Operation #\{id\} is not running.              | You cancelled an operation that had already finished.                             | Nothing to do.                                                                                                      | <small>opNotFound</small>     |
| Not implemented yet.                           | A command has no implementation in this build.                                    | Report it.                                                                                                          | <small>notImplemented</small> |

Other validation messages (code `invalidArgument`) appear under the field you filled, for example "The stash message is empty." or "The depth must be between 1 and …". They describe the fix themselves.
