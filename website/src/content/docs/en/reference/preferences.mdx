This page lists every setting of the **Preferences** dialog, tab by tab. Each row links to the page that explains the feature.

## Open the preferences

- The gear button (**Preferences**) in the title bar.
- <kbd>⌘,</kbd> (<kbd>Ctrl+,</kbd> on Windows and Linux), rebindable.
- **Open preferences** in the [command palette](../../customize/palette-and-shortcuts/).
- On macOS, **yaggui › Preferences…**.
- **Edit shortcuts…** in the keyboard shortcuts sheet opens it on the **Shortcuts** tab.

"Changes apply immediately.": there is no Save or Cancel button, only **Close**. Text fields save when you press <kbd>Enter</kbd> or leave the field. If yaggui refuses a value, the setting goes back to its previous value and a toast "Could not save the preference" explains why. <kbd>Esc</kbd> closes the dialog, except during a shortcut capture, where it only cancels the capture.

| **High contrast** | On, off | Off | Stronger text and borders, with any style |
| **Gravatar avatars** | On, off | Off | Shows authors' Gravatar pictures. Sends the SHA-256 hash of each author e-mail to gravatar.com. Off: no request |

| **Density** | **Comfortable**, **Compact** | **Comfortable** | Row height 28 px or 22 px |
| **Language** | **System**, **English**, **Français** | **System** | Interface language, applied without restart. System uses the OS language if supported, otherwise English |
| **Interface font** | Name of an installed font | Empty (Inter) | Font of the interface |
| **Code font** | Name of an installed font | Empty (JetBrains Mono) | Font of diffs, code, SHAs and the terminal |
| **Text size** | 11 to 18 px | 13 px | Scales all text |

## Behavior

| Label | Values | Default | Effect |
|---|---|---|---|
| **Fetch automatically** | On, off | On | Fetches every open repository in the background. See [Fetch, pull and push](../../remotes/fetch-pull-push/) |
| **Every (minutes)** | 1 to 240 | 10 | Interval of the automatic fetch. Disabled when automatic fetch is off. Out-of-range values are clamped |
| **Prune on fetch** | On, off | On | Adds `--prune` to every fetch: remote-tracking branches deleted on the remote are removed |
| **Default pull strategy** | **Git configuration**, **Fast-forward only**, **Merge**, **Rebase** | **Git configuration** | Used when you pull without choosing. **Git configuration** follows `branch.<name>.rebase`, `pull.rebase` and `pull.ff`, and falls back to fast-forward only |
| **Protected branches** | Branch names or patterns such as `release/*` | `main`, `master`, `develop`, `release/*` | Force push to them is refused, and branch cleanup never lists them. **Restore defaults** brings the default list back. An empty list protects nothing. See [Branches](../../history/branches/) |
| **Confirmations** | One switch per confirmation | All on | See [below](#confirmations-you-can-turn-off) |
| **Check for updates at startup** | On, off | Asked at first launch | Reads the latest release on github.com at each launch. Off: no request. See [Updates](../../start-here/updates/) |
| **Check now** | Button | | Checks for an update immediately |
| **Version** | **What's new** button | | Shows the running version and opens the changelog |

`release/*` matches `release/1.0` but not `release` itself. Up to 100 protected entries are allowed.

## Confirmations you can turn off

The **Confirmations** group of the **Behavior** tab ("Ask before these actions. The dialog always shows what will happen.") has four switches:

| Switch | Confirmation it controls | Can be turned off |
|---|---|---|
| **Discard changes** | "Discard all unstaged changes?", discarding selected files, hunks or lines | Yes |
| **Delete a tag** | "Delete the tag *name*?" | Yes |
| **Drop a stash** | "Drop this stash?" | Yes |
| **Force push** | "Overwrite *branch*?" | No: "Always asked: it rewrites the remote history." |

A turned-off confirmation runs the action at once. Other confirmations are always shown and have no switch, for example: rebase ("Rebase *branch* onto *target*?"), rewriting commits in an interactive rebase, aborting an operation, deleting a remote branch or tag, removing a remote, publishing a branch, deleting a workspace, undo when local changes are in the way, trusting a folder (`safe.directory`) and removing an index lock. Reset and branch deletion use their own dialogs.

## Where preferences are stored

Preferences are not in a `settings.json` file. They are stored in the SQLite database `yaggui.db`, in the `preferences` table (one row per setting, JSON values), in yaggui's configuration folder:

| OS | Configuration folder |
|---|---|
| Linux | `~/.config/dev.tropico.yaggui` (or `$XDG_CONFIG_HOME/dev.tropico.yaggui`) |
| macOS | `~/Library/Application Support/dev.tropico.yaggui` |
| Windows | `%APPDATA%\dev.tropico.yaggui` |

The `YAGGUI_CONFIG_DIR` environment variable replaces this folder.

- Shortcuts are stored separately in `keybindings.json`, in the same folder, which you can edit by hand. See [Edit keybindings.json](../../customize/palette-and-shortcuts/#edit-keybindingsjson).
- Avatars are cached in the OS cache folder, not with the preferences.
- An unreadable or out-of-range value falls back to its default. If the database cannot be opened, yaggui starts with the defaults and does not save changes.
- To reset every preference, quit yaggui and delete `yaggui.db`. This also forgets your repositories, tabs and workspaces. See [Data and privacy](../../reference/data-and-privacy/).

There is no import or export of preferences yet.
