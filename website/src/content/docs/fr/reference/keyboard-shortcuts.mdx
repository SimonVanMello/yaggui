Ce sont les raccourcis par défaut. Chacun peut être modifié dans **Préférences → Raccourcis**, et **⌘K** (**Ctrl+K** sous Windows et Linux) ouvre la palette de commandes, qui liste chaque commande avec son raccourci actuel.

Ce tableau est généré à partir de la liste des commandes de l'application elle-même : il correspond toujours à la version de la documentation que vous lisez.
