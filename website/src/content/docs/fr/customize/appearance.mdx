Le thème de couleurs, le style d’interface et le contraste se règlent dans **Préférences › Apparence** ; les polices, la taille du texte, la densité et les avatars dans **Préférences › Affichage** ; la langue dans **Préférences › Général**. Les changements s’appliquent dès que vous les faites : il n’y a pas de bouton d’enregistrement.

Pour ouvrir les préférences, cliquez sur le bouton en forme d’engrenage (**Préférences**) dans la barre de titre, appuyez sur <kbd>⌘,</kbd> (<kbd>Ctrl+,</kbd> sous Windows et Linux), ou lancez **Ouvrir les préférences** depuis la [palette de commandes](../../customize/palette-and-shortcuts/). Sous macOS, l’entrée de menu **yaggui › Préférences…** les ouvre aussi. La fenêtre s’ouvre sur **Général** : choisissez une section dans la barre latérale, ou tapez dans **Rechercher…** en haut de celle-ci (<kbd>⌘F</kbd>, <kbd>Ctrl+F</kbd> sous Windows et Linux) pour trouver un réglage par son nom, en français ou en anglais. La recherche est décrite dans la [référence des préférences](../../reference/preferences/).

## Choisir un thème de couleurs

La galerie **Thème** montre chaque thème de couleurs sous forme de carte dessinée avec ses propres couleurs (barre de titre, barre latérale, graphe, diff). Il y en a 25, groupés par famille :

| Famille        | Thèmes                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **yaggui**     | Graphite (sombre, par défaut), Paper (clair, par défaut), Terminal (sombre)                                                       |
| **Catppuccin** | Catppuccin Mocha, Catppuccin Macchiato, Catppuccin Frappé (sombres), Catppuccin Latte (clair)                                     |
| **VS Code**    | Dark Modern, Dark+ (sombres), Light Modern, Light+ (clairs)                                                                       |
| **JetBrains**  | Darcula, JetBrains Dark (sombres), JetBrains Light (clair)                                                                        |
| **GitHub**     | GitHub Dark (sombre), GitHub Light (clair)                                                                                        |
| **Classiques** | One Dark, Dracula, Nord, Tokyo Night, Gruvbox Dark, Solarized Dark, Rosé Pine (sombres), Solarized Light, Rosé Pine Dawn (clairs) |

- **Filtrer les thèmes** garde les thèmes dont le nom ou la famille contient ce que vous tapez ; **Tous**, **Sombres** et **Clairs** gardent un seul type. Le compteur à côté indique combien sont affichés.
- **Aperçu** : survolez une carte, ou atteignez-la avec <kbd>Tab</kbd> et les flèches. Après un court délai, toute la fenêtre prend le thème, et une barre indique « Aperçu : _thème_ · clic pour appliquer · Échap pour revenir à _thème actuel_ ». Sortir de la galerie, ou <kbd>Échap</kbd>, revient au thème actuel sans fermer la fenêtre. Un aperçu n’est jamais enregistré.
- **Appliquer** : cliquez sur la carte, ou appuyez sur <kbd>Entrée</kbd> dessus. La carte du thème utilisé est entourée et marquée **Actif** (quand le thème suit l’OS : les deux thèmes utilisés, marqués **Mode clair** et **Mode sombre**).

Les thèmes reprennent les palettes publiées par leurs auteurs. Les couleurs de texte, d’accent et d’état qui seraient difficiles à lire sont un peu éclaircies (sur un thème sombre) ou assombries (sur un thème clair), pour que chaque thème garde le contraste exigé par yaggui (WCAG AA) ; le terminal intégré et la coloration syntaxique gardent les valeurs du thème.

yaggui applique le dernier thème utilisé avant le premier affichage de la fenêtre : une configuration sombre ne produit donc jamais d’éclair blanc au démarrage.

## Suivre le mode clair ou sombre de l’OS

yaggui garde un thème pour le mode clair et un pour le mode sombre. **Suivre le thème du système** (activé par défaut) affiche celui du mode dans lequel est votre OS, et bascule en direct quand l’OS change. Tant qu’il est activé, deux cadres au-dessus de la galerie montrent **Mode clair** et **Mode sombre** avec leur thème, celui utilisé étant marqué **actif**.

- Choisir un thème du mode dans lequel est l’OS remplace le thème de ce mode : yaggui continue de suivre l’OS.
- Choisir un thème de l’autre mode l’affiche et arrête de suivre l’OS (l’interrupteur se désactive), car il ne serait pas visible autrement. Réactivez l’interrupteur pour basculer de nouveau entre vos deux thèmes avec l’OS.
- Désactiver l’interrupteur garde le thème affiché.

Par exemple, pour Catppuccin Latte le jour et Catppuccin Mocha la nuit : choisissez **Catppuccin Latte**, puis **Catppuccin Mocha**, puis activez **Suivre le thème du système**.

## Choisir un thème depuis la palette de commandes

Sans ouvrir les préférences :

1. Appuyez sur <kbd>⌘K</kbd> (<kbd>Ctrl+K</kbd>), tapez `thème` et appuyez sur <kbd>Entrée</kbd> sur **Thème : choisir un thème de couleurs…**.
2. La palette liste les **Thèmes sombres** puis les **Thèmes clairs**, en partant du thème actuel (marqué **actuel**). Tapez pour filtrer par nom ou par famille.
3. Déplacez-vous avec <kbd>↑</kbd> <kbd>↓</kbd> : chaque thème atteint est prévisualisé sur toute la fenêtre.
4. Appuyez sur <kbd>Entrée</kbd> pour l’appliquer, ou sur <kbd>Échap</kbd> pour revenir au thème actuel.

La même règle que dans la galerie s’applique quand le thème suit l’OS. La palette propose aussi **Thème : suivre le système**, **Thème : clair** et **Thème : sombre**, qui changent de mode en gardant le thème de chaque mode ; l’entrée du mode actuel est grisée.

## Choisir le style d’interface

**Style d’interface** accepte **Standard** (par défaut) ou **Terminal** : « Terminal : monospace, angles droits, lignes denses. Se combine avec tous les thèmes. » Il ne change que la forme de l’interface, pas ses couleurs. Pour retrouver tout l’aspect de l’ancien style Terminal, choisissez **Terminal** ici et le thème de couleurs **Terminal**.

Si vous utilisiez le style Terminal dans une version précédente, yaggui garde son aspect : le thème Terminal devient votre thème sombre et le mode passe en sombre. Un fichier de préférences exporté par une version précédente est traité de la même façon à l’import.

## Activer le contraste élevé

**Contraste élevé** (désactivé par défaut, dans **Apparence**) renforce le texte et les bordures. C’est un interrupteur, pas un thème à part : il fonctionne avec tous les thèmes de couleurs. Dans le [terminal intégré](../../repository/terminal/), il impose aussi un rapport de contraste minimal aux couleurs du shell.

## Changer la densité

Dans **Préférences › Affichage**, **Densité** accepte **Confortable** (par défaut) ou **Compacte**. Le mode compact réduit la hauteur des lignes (graphe, listes, journal des commandes, palette et autres) de 28 px à 22 px, pour en afficher davantage à l’écran.

## Changer les polices et la taille du texte

Ces réglages se trouvent dans **Préférences › Affichage**, sous **Texte**.

| Réglage                   | Valeur par défaut                       | Effet                                                                                       |
| ------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Police de l'interface** | Vide : la police Inter fournie          | Police des menus, des libellés et des listes                                                |
| **Police du code**        | Vide : la police JetBrains Mono fournie | Police des diffs, de la vue blame, des SHA, du journal des commandes et du terminal intégré |
| **Taille du texte**       | 13 px                                   | Curseur de 11 à 18 px. Redimensionne tous les textes de l’application                       |

Pour les deux champs de police :

1. Saisissez le nom d’une police installée sur votre système, par exemple `Fira Code`.
2. Appuyez sur <kbd>Enter</kbd> ou quittez le champ. La police s’applique aussitôt.

Un champ vide rétablit la police fournie. Si la police n’est pas installée, le système se rabat sur la police fournie. Un nom de plus de 200 caractères, ou contenant des caractères de contrôle ou l’un des caractères `; { } < > \ " '`, est refusé : un toast « Impossible d'enregistrer la préférence » indique « \{name\} » n’est pas un nom de police valide, et la police précédente reste en place.

## Changer la langue

Dans **Préférences › Général**, **Langue** accepte **Système** (par défaut), **English** ou **Français**. **Système** utilise la première langue de votre OS que yaggui prend en charge, et l’anglais à défaut. Le changement s’applique immédiatement, sans redémarrage ; sous macOS, la barre de menus est reconstruite dans la nouvelle langue.

La langue concerne toute l’interface, y compris les messages d’erreur de yaggui. La sortie brute de Git affichée dans le [journal des commandes](../../reference/command-log/) reste en anglais.

## Afficher les avatars des auteurs (Gravatar)

Par défaut, yaggui affiche les initiales de chaque auteur dans le graphe, le détail d’un commit et le panneau de comparaison. Il n’envoie aucune requête réseau pour les avatars.

Activez **Avatars Gravatar** (**Préférences › Affichage**, sous **Avatars**) pour afficher à la place les photos [Gravatar](https://gravatar.com) des auteurs :

- **Ce qui est envoyé** : pour chaque auteur, yaggui calcule sur votre machine le hash SHA-256 de l’adresse e-mail, puis demande `https://www.gravatar.com/avatar/<hash>?s=40&d=404` en HTTPS, sans référent. L’adresse e-mail elle-même ne quitte jamais votre machine.
- **Pas de photo** : quand une adresse n’a pas de Gravatar, les initiales restent affichées. yaggui s’en souvient pendant 2 jours pour ne pas redemander à chaque réaffichage.
- **Cache** : les photos téléchargées sont stockées dans un dossier `avatars-v1` du dossier de cache de yaggui (voir [Données et confidentialité](../../reference/data-and-privacy/)) et renouvelées au bout de 7 jours. Le cache est plafonné à 20 Mo et 10 000 entrées ; les plus anciennes partent en premier. Hors connexion, une photo expirée reste affichée.
- **Vider le cache des avatars** supprime toutes les photos téléchargées (« Cache des avatars vidé »). Elles sont téléchargées de nouveau la prochaine fois qu’elles sont affichées, si l’interrupteur est activé.

Désactiver l’interrupteur arrête aussitôt toutes les requêtes ; les photos déjà en cache restent sur le disque jusqu’à leur expiration ou jusqu’à ce que vous les vidiez.

## Animations réduites

yaggui n’a pas de réglage propre pour les animations. Il suit le réglage de réduction des animations de votre OS (`prefers-reduced-motion`) : lorsqu’il est activé, les transitions sont instantanées et la barre de progression indéterminée cesse de défiler.
