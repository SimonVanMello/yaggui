Ces pages expliquent comment fonctionne yaggui : d’où part chaque action, ce qu’elle affiche avant de s’exécuter, quelle commande Git elle lance, ce qui peut mal tourner et ce qui peut être annulé. Git lui-même est expliqué par la [documentation de Git](https://git-scm.com/doc) ; ces pages y renvoient quand un concept compte.

Vous découvrez yaggui ? Lisez l’[introduction](start-here/introduction/), [installez-le](start-here/install/), puis faites la [visite de la fenêtre](start-here/tour/).
