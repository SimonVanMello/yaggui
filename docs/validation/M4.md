# Manual validation of milestone M4 (= V1)

Guide for validating M4 (undo / redo, workspaces, file history, blame and reflog, submodules, worktrees and LFS, preferences and shortcuts, commit and stash, graph, diff and branches, remotes and tags, integrated terminal, rename to yaggui) on **macOS** and **Windows**, plus two Linux items. Allow about 2 h per OS, plus 1 h when M2 and M3 are also revisited (§0).

The status of the V1 requirements, the major gaps and the performance measurements are in [V1-audit.md](V1-audit.md). Prerequisites and launch are the same as in [M0.md](M0.md) §1–2, and the checklist conventions as in [M1.md](M1.md) §2.

```bash
git pull && pnpm install
pnpm tauri dev                          # dev mode
pnpm tauri build --debug --no-bundle    # binary with the production CSP (use it to validate screens)
YAGGUI_CONFIG_DIR=/an/empty/dir pnpm tauri dev   # isolated session: no existing repositories or preferences
```

The nonce-based CSP does not exist under `pnpm tauri dev`. Blame, image diff, the config editor and above all the **integrated terminal** (xterm injects `<style>` elements) must be validated **with the `build --debug` binary**.

## 1. Setup

### Rename (M4-10)

- [ ] **New config folder** — Expected: on first launch, the database is created in `~/Library/Application Support/dev.tropico.yaggui/yaggui.db` (macOS) or `%APPDATA%\dev.tropico.yaggui\yaggui.db` (Windows). The app menu (macOS) and the window title say "yaggui".
- [ ] **Old data to delete** (the app was never distributed, nothing is migrated):
  - macOS: `~/Library/Application Support/grove` (with `grove.db`), `~/Library/WebKit/dev.grove.app`, `~/Library/Caches/dev.grove.app`;
  - Windows: `%APPDATA%\grove` (or `Grove`), `%LOCALAPPDATA%\dev.grove.app`;
  - Linux: `~/.config/grove`, `~/.cache/dev.grove.app`, `~/.local/share/dev.grove.app`.

  Expected: after deletion, yaggui starts normally, without recreating anything under `grove`.
- [ ] **Existing clones**: after the GitHub repository rename, run `git remote set-url origin <new URL>` in each clone.

### Test repositories

Replace `$W` with an empty folder (on Windows: Git Bash, with `C:/…` paths). The script below creates a `work` repository with a local remote, merged and `[gone]` branches, a tag, a renamed file (for history), an image, an executable file, a submodule and a worktree.

```bash
git init -q --bare -b main $W/remote.git
git init -q -b main $W/lib && cd $W/lib && echo lib > lib.txt && git add -A && git commit -qm "lib" && cd -
git clone -q file://$W/remote.git $W/work && cd $W/work
printf 'one\ntwo\nthree\n' > notes.txt && git add -A && git commit -qm "notes"
git mv notes.txt doc.txt && printf 'one\ntwo\nthree\nfour\n' > doc.txt && git commit -qam "rename notes to doc"
for i in 1 2 3; do echo "line $i" >> doc.txt; git commit -qam "doc $i"; done
printf '\x89PNG\r\n\x1a\nv1' > logo.png && printf '#!/bin/sh\necho hi\n' > run.sh && git add -A && git commit -qm "assets"
git tag -a v1.0 -m "v1.0" && git push -q origin main v1.0
git switch -qc feat/merged && echo m > m.txt && git add m.txt && git commit -qm "merged" && git switch -q main && git merge -q --no-ff feat/merged -m "merge feat/merged"
git switch -qc gone-branch && echo g > g.txt && git add g.txt && git commit -qm "gone" && git push -q -u origin gone-branch && git switch -q main
git push -q origin --delete gone-branch && git fetch -q --prune
git -c protocol.file.allow=always submodule add -q $W/lib lib && git commit -qm "add lib submodule"
git worktree add -q -b review ../work-review
git push -q origin main
```

For **LFS** (`git lfs` installed): `git lfs install --local && git lfs track "*.bin" && head -c 200000 /dev/urandom > big.bin && git add -A && git commit -qm lfs`.

For **signing**: an SSH key (`git config gpg.format ssh`, `user.signingkey ~/.ssh/id_ed25519.pub`, `commit.gpgsign true`) or GPG, depending on the usual setup.

## 2. Checklist

Tick each item; "Expected" describes the correct behavior. `⌘` = `Ctrl` and `⌥` = `Alt` on Windows. After each write, check the actual state in a terminal (`git status`, `git log --oneline --graph --all`, `git config -l --local`): the UI must say the same as Git. The command log (status bar → "Log") must list every command run.

### Undo / redo (M4-1, M4-2)

- [ ] **`⌘Z` / `⌘⇧Z` outside a text field** after each F-240 operation: commit, amend, checkout, branch creation / deletion / rename, merge, reset, discard, stash deletion, cherry-pick, revert — Expected: "Undone: …" toast; the Git state goes back exactly to the previous state, then to the following one with `⌘⇧Z` (refs, HEAD, index, files, upstreams).
- [ ] **(win)** **`Ctrl+Y`** also redoes.
- [ ] **(mac)** **Native menu Edit › Undo / Redo**: it triggers yaggui's undo outside a text field, and the field's undo inside a text field (commit message, search) or in CodeMirror (3-way editor). No stray character is inserted.
- [ ] **Toolbar button** — Expected: the tooltip names the operation; after a push or a fetch with prune, it is disabled and the tooltip says why; `⌘Z` then shows "Cannot undo" and does nothing.
- [ ] **Session history** (arrow next to the button, or palette "Show the operation history") — Expected: most recent first, time, undone operations marked.
- [ ] **Commit made in a terminal** after a branch creation in yaggui, then `⌘Z` — Expected: refused with "the repository changed since", naming the ref, and nothing is modified.
- [ ] **Discard, then edit the same file in an editor, then `⌘Z`** — Expected: "Local changes are in the way" with the file; "Stash and retry" undoes the discard and puts the edit in a stash (to recover with a pop).
- [ ] **Undoable M4 operations** — Expected, for each one, `⌘Z` then `⌘⇧Z` matching the Git state: partial stash, add to `.gitignore`, branch cleanup (both branches come back, with the upstream of `gone-branch`), remote add / rename / delete, **remote URL change** (`git remote -v`), local tag creation and deletion, worktree creation (folder removed), deletion of a clean worktree, `lfs track` (`.gitattributes`), restore from the reflog (branch creation or reset).
- [ ] **Non-undoable M4 operations** — Expected: entry disabled with its reason for pushing one tag or all tags ("push of every tag to origin"), `lfs pull`, submodule update and forced deletion of a modified worktree. Settings (Git config, identity profile, graph filter, workspaces) do not appear in the history.
- [ ] **(win)** **Discard then undo** of an executable file and of a symlink (without `core.symlinks`) — Expected: content restored; the symlink comes back as a file containing its target (Windows limitation).
- [ ] **(mac)** **Branch rename that only changes case** (`feat` → `Feat`), then undo — Expected: no error, `git branch` matches.

### Workspaces (M4-3)

- [ ] **Create a workspace, add known repositories to it, "Open all"** — Expected: one tab per repository, already open ones are reused.
- [ ] **Scan a folder** (native picker): `~/dev` or `C:\src`, depth 1 then 3 — Expected: responsive, nested repositories and `node_modules` ignored; paths are shown **(win)** without the `\\?\` prefix.
- [ ] **Overview** — Expected: branch, ahead / behind, dirty state and last fetch per repository; "Fetch all" on about ten repositories with SSH or HTTPS authentication through a helper, without a prompt.
- [ ] **Moved or deleted repository** (rename the folder outside yaggui) — Expected: reported on open; "Locate…" (native picker) or "Remove from …" work.

### File history, blame, reflog (M4-4)

- [ ] **History of `doc.txt`** (file context menu, or palette on the displayed file) — Expected: commits go back past the rename ("from notes.txt"); diff per commit; `j` / `k` navigate.
- [ ] **Blame** — Expected: age shades readable in both themes; an uncommitted modified line is marked; click → commit selected in the graph; "Blame of the parent" crosses the rename, with a way back.
- [ ] **Blame of a large file** (several thousand lines) in WKWebView / WebView2 — Expected: smooth scrolling, shades (`color-mix`) rendered correctly.
- [ ] **(win)** **CRLF file, non-UTF-8 file** (encoding chip) and **non-ASCII path** (`folder é/ü.txt`) in working-copy blame (`git blame --contents -`).
- [ ] **Reflog of HEAD and of a branch** (ref menu → "Reflog") — Expected: colored actions, pruned commits struck through; "Create a branch here…" and "Reset main here…" (dialog with the lost files) produce the announced state, undoable with `⌘Z`.

### Submodules, worktrees, LFS (M4-5)

- [ ] **Submodule `lib`** — Expected: expected / current state; after `cd lib && git commit --allow-empty -m x`: modified pointer reported; "Update" restores the recorded commit; "Open the submodule" opens a tab.
- [ ] **Submodule with an authenticated SSH or HTTPS URL** — Expected: fast `authFailed`, no blocking prompt.
- [ ] **Worktree**: create (new or existing branch, suggested folder, "Choose…" on macOS), open in a tab, delete (confirmation; explicit force if modified), prune after deleting the folder outside yaggui — Expected: `git worktree list` matches; **(win)** paths with `\` and opening in a tab without the `\\?\` prefix.
- [ ] **Undo of a worktree creation / deletion** from the toolbar, with that worktree open in another tab.
- [ ] **LFS** — Expected: "LFS" badge on `big.bin`, no text diff of the pointer; `lfs track "*.dat"` modifies `.gitattributes`; `lfs pull` on a real LFS server shows progress and can be cancelled; without `git lfs` installed, a warning and nothing blocking. **(win)** Git for Windows' `git lfs` detected (version).

### Preferences and shortcuts (M4-6)

- [ ] **Shortcuts** ("Preferences" › "Shortcuts"): rebind "Fetch" to another key, a shortcut with `⌃` **(mac)**, remove a shortcut, conflict with another one — Expected: immediate effect; `keybindings.json` in the config folder contains the change; the native menu **(mac)** shows the new shortcut.
- [ ] **Shortcut sheet `⌘/`** — Expected: reflects the rebinds. On an **AZERTY** keyboard, `⌘/` requires Shift: note whether the default shortcut is awkward (it can be rebound).
- [ ] **FR / EN language** — Expected: immediate switch of the whole UI, native menus included.
- [ ] **Tools**: external editor (`code`, `subl`, **(mac)** `open -a <App>`, **(win)** path with spaces), external terminal, diff and merge tools — Expected: each one launches from the place that uses it.
- [ ] **Git config** (global and local): identity, `pull.rebase`, `core.autocrlf`, `init.defaultBranch`, signing, then raw editing — Expected: `git config -l --show-origin` matches; an invalid value is refused with a message.
- [ ] **High contrast** and **D · Terminal style** — Expected: every screen of this checklist stays readable.

### Commit and stash (M4-7a)

- [ ] **Signing** — Expected: "Signed · SSH / GPG" chip in the commit panel; verified / unverified badge in the commit details, with the reason in a tooltip (without `gpg.ssh.allowedSignersFile`: "Signed, not verified").
  - **(mac)** GPG with pinentry-mac, and SSH through the keychain (`ssh-add --apple-use-keychain`).
  - **(win)** gpg4win, with `gpg.program` pointing to its gpg; OpenSSH Authentication Agent service started.
  - Locked key or passphrase missing from the agent: the graphical pinentry opens, or `signingFailed` ("passphrase"). yaggui never hangs.
- [ ] **Templates** (`commit.template` and custom templates), **Conventional Commits helper**, **recent messages** — Expected: the prefilled message is correct, and the template's `#` lines are stripped on commit.
- [ ] **Identity profiles** — Expected: applying a profile writes `user.name` / `user.email` locally (`git config --local -l`).
- [ ] **Add to `.gitignore`** (file, extension, folder) — Expected: the rule is added only once; **(win)** with `core.autocrlf`, a CRLF `.gitignore` keeps its CRLF.
- [ ] **Partial stash** of two files out of three, with paths containing spaces and accents (**(mac)** NFD) — Expected: only those files go back to HEAD; "Pop" restores them.

### Graph, diff and branches (M4-7b)

- [ ] **Hide / solo a branch, hide remotes and stashes** — Expected: the filter status bar is visible, and the filter is kept after a restart.
- [ ] **Compare two commits** (`⌘`-click) and **two branches** — Expected: commits on each side, overall diff, clickable merge-base.
- [ ] **Jumps**: HEAD (`⌘⇧H`), branch (palette), merge-base of the selection.
- [ ] **Gravatar** ("Preferences" › "Appearance", off by default) with network access — Expected: off, no request to `gravatar.com`; on, images are shown, and an address without a Gravatar keeps its initials. Note whether images reload often: the cache is the webview's, valid for 5 min.
- [ ] **Image diff** (`logo.png` modified, then an SVG) in WKWebView / WebView2 — Expected: side by side, overlay (opacity), slider; the SVG is rendered as an image.
- [ ] **Mode, line endings, submodule** (`chmod +x run.sh`, CRLF conversion, `lib` pointer) — Expected: the diff states explicitly what changed.
- [ ] **"Open outside yaggui"**: external diff tool (FileMerge / opendiff, WinMerge, Meld) — Expected: it launches, and the repository is not blocked while it stays open. "Show in the file manager": **(mac)** Finder selects the file, **(win)** so does Explorer (`explorer /select,`).
- [ ] **Branch cleanup** (palette "Clean up merged and gone branches…") — Expected: `feat/merged` pre-checked, `gone-branch` offered but unchecked, `main` and protected branches listed separately; deletion then `⌘Z` give a matching Git state.

### Remotes and tags (M4-7c)

  - HTTPS remote with the system credential helper.
  - **(win)** Local path as URL (`C:\repos\x.git`).
- [ ] **Tags**: push a tag, push all tags, fetch tags, delete a remote tag — Expected: `git ls-remote --tags origin` matches; a tag already present on a real server with a different target gives `tagRejected`.
- [ ] **Checkout of tag `v1.0`** — Expected: detached HEAD explained, branch creation offered.

## 3. OS-specific items

- [ ] **(mac)** **(win)** **CSP**: with the `build --debug` binary, open each new M4 screen (blame, image diff, terminal, config editor, Gravatar on) — Expected: nothing is displayed unstyled. To check, open the webview inspector: no `Content-Security-Policy` violation in the console.
- [ ] **(linux)** **Wayland** (PR #33): in a Wayland session (GNOME, KDE), launch the binary — Expected: the window opens without "Error 71 (Protocol error) dispatching to Wayland display". yaggui sets `WEBKIT_DISABLE_DMABUF_RENDERER=1` when `WAYLAND_DISPLAY` is defined or `XDG_SESSION_TYPE=wayland`. With `WEBKIT_DISABLE_DMABUF_RENDERER=0` already exported, the existing value is respected (the crash may then come back, which is expected).
- [ ] **(linux)** **X11** — Expected: the variable is not set (`cat /proc/<pid>/environ | tr '\0' '\n' | grep WEBKIT` returns nothing).

## 4. Known limitations (accepted for M4)

- **Undo**: in-memory journal, lost when the repository is closed (persistence: V2). A deleted stash comes back at the top of the list. Undoing a remote deletion does not restore `branch.<b>.pushRemote` or `remote.pushDefault`. Ignored files of a deleted worktree do not come back.
- **Signing**: the badge is in the commit details, not in the graph rows (major gap F-066, see [V1-audit.md](V1-audit.md) §2).
- **Gravatar**: no dedicated disk cache, it is the webview's HTTP cache (major gap F-033).
- **Comparison**: overall "tip to tip" diff, not `B...A`.
- **Worktrees**: `lock` / `unlock` / `move` not exposed. A `git worktree add` run in a terminal on an existing branch only appears at the next refs refresh.
- **Terminal**: no clickable URLs, no scrollback search; the panel height and the number of terminals are not kept between sessions.
- **Shortcuts**: no detection of OS-reserved shortcuts.
- **Git config**: a multi-valued key (`remote.origin.fetch`) is deleted as a whole, it cannot be edited in place.
- **Palette**: history and blame are only offered for the displayed file.
- **Bisect**: detection, skip and finish only (good / bad: V2).

## 6. Expected report

For each failing item, provide:

- the OS, the step, and what was observed (a screenshot if it is visual);
- the command log entry (status bar → "Log": command, exit code, stderr);
- the output of `git status` and `git log --oneline --graph --all -10`.

Depending on the item, add:

- undo: the content of the session history;
- terminal: the shell, the OS version and the keyboard layout;
- signing: `git config --get-regexp 'gpg|commit.gpgsign|user.signingkey'`;
- Wayland: `echo $XDG_SESSION_TYPE $WAYLAND_DISPLAY`, the compositor and the graphics driver.
