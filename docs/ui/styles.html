UI style proposals

One mockup, four themes applied through design tokens: the same theming architecture the app uses. Switch style and screen to compare the same situations: graph + staging, diff, command palette, branch drag & drop, rebase with a conflict.

The four styles

Comparison

StyleProposed roleStrengthsRisks
A · GraphiteDark defaultUnderstated, comfortable for long sessions, the graph stands out; the single accent makes primary actions obvious.A bit austere if the lanes are desaturated.
B · PaperLight defaultReassuring for beginners, native macOS feel, great in daylight.Lane colors must be darkened to stay AA.
C · AuroraOptional themeClosest to the GitKraken energy, very recognizable, friendly rounded pills.Tires the eyes faster, looks less "pro" in front of a client.
D · TerminalOptional themeMaximum density, consistent with keyboard-first use.Off-putting for beginners: against the goal if used as the default.

Recommendation: A + B as the default pair (same tokens, switched by the system theme), C and D as options. Density is a setting independent of the style.
